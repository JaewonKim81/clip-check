# 금칙 판정 기준 (방송심의에 관한 규정 기반)

> 이 파일은 코드와 분리된 판정 기준이다. **이 파일만 수정하면 다음 영상부터 즉시 반영**된다 (재배포 불필요).
> 판정 시 반드시 해당 조문을 근거로 제시한다.

## 판정 카테고리 (8종)

`성표현` `폭력` `충격혐오` `유해행위` `인격권` `차별증오` `아동청소년` `광고저작권`

## 심각도 등급

| 점수 | 판정 | 의미 |
|------|------|------|
| 0 | 통과 | 문제 없음 |
| 1–2 | 주의 | 경미한 위반 — 기록하되 방영 가능 |
| 3 | 경고 (검토 필요) | 경계 사례 — 사람이 최종 확인 |
| 4–5 | 방영 불가 | 명백한 중대 위반 |

## 카테고리별 기준

### 성표현 (방송심의 §29 선정성)
- 신체 일부 노출(수영복·운동복 등 맥락상 자연스러운 경우) = 0~1
- 속옷 노출 = 1~2 (주의)
- **의도적 탈의·성적 어필 = 4 (방영 불가)** — 방송 중 옷을 벗으며 성적 어필을 시도하는 행위는 노출 정도와 무관하게 방영 불가
- 성행위 묘사·암시 = 4~5

### 폭력 (방송심의 §35 폭력묘사)
- 가벼운 신체 접촉·장난 = 0~1
- 밀치기·붙잡기 등 의도성이 모호한 물리적 충돌 = 3 (검토 필요)
- **신체에 대한 직접 가격(뺨 때리기·주먹질·발길질·머리채 잡기) = 4 (방영 불가)**
- 무기 사용·집단 폭행·잔혹한 폭력 = 5

### 충격혐오 (방송심의 §36 충격·혐오감)
- 가벼운 상처·혈흔의 짧은 노출 = 1~2
- 상해 부위의 직접 노출 = 3
- 시신·신체 훼손·잔혹 장면 = 4~5

### 유해행위 (방송심의 §28 유해행위 모방)
- 미화 없는 흡연·음주 장면 = 1~2
- 흡연·음주의 미화, 위험 행동 모방 유도 = 3
- 자해·자살 묘사, 마약 사용 묘사 = 4~5

### 인격권 (방송심의 §21 사생활·인격권)
- 일반인 얼굴이 모자이크 없이 식별 가능 (동의 불명) = 1~2 + 검토 필요
- 사생활 침해 소지가 있는 촬영물 = 3
- 명예훼손·모욕 의도가 명백한 내용 = 4

### 차별증오 (방송심의 §27 차별·비하 표현)
- 특정 집단 비하 발언 (인용·비판 맥락 가능성 있음) = 3 (검토 필요)
- 명백한 차별·혐오 조장 발언 = 4~5

### 아동청소년 (방송심의 §43~45 어린이·청소년 보호)
- 아동·청소년이 유해 상황에 노출되는 장면 = 3 이상
- 아동·청소년 대상 성적 묘사 = 5 (즉시 방영 불가)

### 광고저작권 (방송심의 §46 간접광고·저작권)
- 상표 로고의 짧은 노출 = 0~1
- 특정 상표 로고가 화면 중앙에 장시간 노출 (간접광고 가능성) = 1~2
- 저작권 침해가 명백한 콘텐츠 사용 = 3 이상

## 판정 원칙

1. 정지 화면 1장이 아니라 **연속 2~3장의 흐름**으로 동작을 판단한다 (때리기·밀치기 등).
2. 해당 구간의 **대사·소리(비명·욕설 등)도 판단 근거**로 함께 사용한다.
3. 모호하거나 경계에 있는 사례는 자동 통과시키지 않고 **검토필요(needsReview)** 로 분류한다.
4. 확신이 없으면 심각도를 낮추는 것이 아니라 **검토필요로 올린다**.
